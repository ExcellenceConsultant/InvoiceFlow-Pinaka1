TAX RESOLUTION PRIORITY (QB STYLE)
================================

Resolve tax exactly like QuickBooks:

1. If customer is tax_exempt → use NON taxable tax code
2. If customer has qb_tax_code_id → use it
3. Else if product has qb_tax_code_id → use it
4. Else use company default tax code
