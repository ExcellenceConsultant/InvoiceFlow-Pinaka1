Enhance the existing **Orders module** with the following features.

Current state:
- Orders module already exists
- Tabs: Sales Orders (SO) and Purchase Orders (PO)

New Requirements:

--------------------------------
1. Send to Invoice / Bill Button
--------------------------------

Add a new action button in the Orders listing table:

- Button label:
  - Sales Order → “Send to Invoice”
  - Purchase Order → “Send to Bill”

Button visibility rules:
- Show ONLY when:
  - Order status === "finalized" OR "approved"
- Hide for:
  - draft / cancelled orders

Button behavior:
- On click:
  - Create a NEW record in **Business module**
    - Sales Order → Invoice (AR)
    - Purchase Order → Bill (AP)
  - Copy data:
    - Customer / Vendor
    - Line items
    - Quantity
    - Cartons
    - Amount
    - Taxes
    - Reference orderNumber
  - Redirect user to:
    - Business → Invoices tab (for SO)
    - Business → Bills tab (for PO)
  - Show success toast:
    “Order successfully sent to Invoice/Bill”

After sending:
- Mark order with:
  - isConverted = true
  - convertedDocumentId
- Disable Send button once converted

--------------------------------

Packing Slip should exist ONLY in Orders module.

Add actions in Orders:
- “View Packing Slip”
- “Print Packing Slip”

Packing Slip rules:
- Available for Sales Orders only
- Can be viewed for:
  - finalized / approved / converted orders

Packing Slip content:
- Company header
- Order Number
- Order Date
- Customer name & address
- Product name
- Quantity
- Cartons
- Notes (optional)
- NO pricing
- NO tax
- NO totals

Implementation:
- Create `PackingSlipView` component
- Printable layout (A4)
- Use window.print() or existing print utility
